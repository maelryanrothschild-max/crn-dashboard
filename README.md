# Дашборд обучения CRN GROUP — деплой на Vercel

Веб-версия дашборда: у каждого сотрудника свой логин (фамилия) и пароль
(личный номер), прогресс хранится в общей базе данных — модератор/директор
видят прогресс всех сотрудников с любого устройства, в реальном времени.

## Новое в этой версии

- **Поиск** сотрудника по имени/фамилии + **фильтры** по городу, магазину, бренду, должности
- **Рейтинг знаний** — отдельная вкладка с сортировкой по среднему баллу тестов
- **Экспорт в Excel** — кнопка «Скачать в Excel» выгружает прогресс команды (с учётом активных фильтров) одним файлом, включая баллы по каждому блоку
- **Импорт из Excel** — массовая загрузка сотрудников файлом .xlsx (колонки: Фамилия, Имя, Должность, Город, Магазин, Бренд), личные номера присваиваются автоматически; на вкладке «Сотрудники» есть кнопка со скачиванием готового шаблона
- **Резервная копия** — отдельная вкладка: скачать полный дамп базы (сотрудники + прогресс + ИИ-блоки) в один клик, и восстановить из файла при необходимости
- **ИИ-генерация новых блоков обучения** — вкладка «ИИ-блоки»: указываете тему (например, «работа с VIP-клиентами», «сервис в пиковые часы») — ИИ готовит теорию, скрипт, кейс, чек-лист и тест из 10 вопросов с учётом специфики розницы Казахстана; после проверки блок добавляется в общий список для всех
- **ИИ-анализ сотрудника + печать отчёта** — в карточке сотрудника кнопка «Отчёт для печати / ИИ-анализ»: таблица баллов по всем блокам + кнопка «Сгенерировать ИИ-анализ» (сильные/слабые стороны, рекомендация) + кнопка печати/сохранения в PDF — удобно отправлять директорам

### Важно: для ИИ-функций нужен ключ Anthropic

Генерация новых блоков и анализ сотрудника работают только если в проекте
задана переменная окружения `ANTHROPIC_API_KEY`. Без неё всё остальное
(тесты, прогресс, Excel, фильтры, резервная копия) работает как обычно, а
ИИ-кнопки покажут понятное сообщение с просьбой добавить ключ.

**Как получить и подключить ключ:**
1. Зайдите на [console.anthropic.com](https://console.anthropic.com), создайте API-ключ (раздел **API Keys**)
2. В Vercel: проект → **Settings → Environment Variables**
3. Добавьте переменную `ANTHROPIC_API_KEY` со значением вашего ключа
4. **Deployments** → у последнего деплоя **⋯ → Redeploy**

## Что внутри

- `pages/index.js` — главная страница (стили + подключение Excel-библиотеки)
- `public/app.js` — вся логика интерфейса
- `public/xlsx.full.min.js` — библиотека для чтения/записи Excel (работает без интернета/CDN)
- `pages/api/login.js` — проверка фамилии и пароля
- `pages/api/roster.js` — список сотрудников (добавление, массовая загрузка, удаление)
- `pages/api/progress/[id].js` — прогресс конкретного сотрудника
- `pages/api/report.js` — агрегированная аналитика (для команды, рейтинга, Excel-экспорта)
- `pages/api/backup.js` — резервное копирование/восстановление
- `pages/api/customblocks.js` — управление ИИ-сгенерированными блоками
- `pages/api/ai/generate-block.js` — генерация нового учебного блока через Claude
- `pages/api/ai/analyze-employee.js` — текстовый анализ результатов сотрудника через Claude
- `lib/redis.js` — подключение к базе данных (Upstash Redis)
- `lib/anthropic.js` — обёртка для вызовов Claude API
- `lib/defaultRoster.js` — стартовый список сотрудников (с городом/магазином/брендом)
- `lib/blockMeta.js` — названия 12 базовых блоков (используется в отчётах)

## Деплой — пошагово (10–15 минут, без опыта программирования)

### Шаг 1. Загрузите код на GitHub
1. Зайдите на [github.com](https://github.com), создайте бесплатный аккаунт (если ещё нет)
2. **New repository** → назовите, например, `crn-dashboard` → **Create repository**
3. На странице репозитория нажмите **uploading an existing file**, перетащите
   туда всё содержимое этой папки (файлы и подпапки `pages`, `public`, `lib`,
   `package.json`, `next.config.js`, `README.md`)
4. **Commit changes**

### Шаг 2. Создайте проект на Vercel
1. [vercel.com](https://vercel.com) → **Sign Up** → **Continue with GitHub**
2. **Add New → Project** → выберите репозиторий `crn-dashboard`
3. Framework Preset определится автоматически как **Next.js** — ничего не меняйте
4. **Deploy**, дождитесь окончания сборки

### Шаг 3. Подключите базу данных
1. Вкладка **Storage** → **Create Database** → **Browse Marketplace** → **Upstash** → **Redis**
2. Подтвердите создание, затем **Connect to Project** → выберите `crn-dashboard`
3. **Settings → Environment Variables** — убедитесь, что появились `KV_REST_API_URL` и `KV_REST_API_TOKEN` (или `UPSTASH_REDIS_REST_URL`/`UPSTASH_REDIS_REST_TOKEN` — код поддерживает оба варианта)
4. **Deployments** → у последнего деплоя **⋯ → Redeploy**

### Шаг 4. (Опционально) Подключите ИИ-функции
См. раздел «Важно: для ИИ-функций нужен ключ Anthropic» выше.

### Шаг 5. Готово — раздайте ссылку сотрудникам
Ссылка вида `https://crn-dashboard.vercel.app`. Каждый входит под своей
фамилией и личным номером. Модератор/директор входят и во вкладке
«Сотрудники» добавляют реальных людей — вручную или сразу списком из Excel.

## Проверка, что всё работает

Откройте `https://ваш-сайт.vercel.app/api/roster` — если видите JSON со
списком сотрудников, база подключена. Если текст об ошибке — вернитесь к
Шагу 3 и убедитесь, что сделан Redeploy после подключения базы.

## Обновление контента (тексты блоков, тесты)

12 базовых блоков — в начале `public/app.js`, массив `BLOCKS`. ИИ-блоки
добавляются прямо через интерфейс (вкладка «ИИ-блоки») без правки кода.
